# 2ASSE – Prénom NOM

Dépôt de rendu du module **2ASSE – Architecture bas niveau et assembleur** (École Hexagone, B2, 2026-2027).

## Contenu

| Dossier | Contenu |
|---|---|
| `tp1/` | TP1 – Premiers programmes |
| `tp2/` | TP2 – Boucles, tableaux et fonctions |
| `tp3/` | TP3 – Le défi crackme |

Chaque dossier contient les programmes (`.asm`) et un fichier `answers.md` avec mes réponses aux questions du TP.

## Assembler et exécuter

Dans le terminal, depuis le dossier d'un TP :

```bash
make hello      # assemble hello.asm et crée l'exécutable hello
./hello         # exécute le programme
echo $?         # affiche son code de retour
gdb -q ./hello  # ouvre le programme dans le débogueur
```
